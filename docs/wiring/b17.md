# B17 wiring: model picker, accelerator, benchmark, downloads

New: `image/models/ModelSpec.kt` (ModelSpecs.ALL, ModelSpecs.byId), `image/models/ModelManager.kt`,
`OnnxLineArtModel` (Accel enum, benchmark, selectAccel). `INTERNET` permission added to the manifest.

## ViewModel
```kotlin
private val models = ModelManager(app)
private val prefs = app.getSharedPreferences("sketcher_ml", Context.MODE_PRIVATE)
// persist the picked model id yourself, e.g. prefs "model_id" (default ModelSpecs.DEFAULT_ID)

private fun model(): OnnxLineArtModel = lineArtModel ?: buildModel().also { lineArtModel = it }
private fun buildModel(): OnnxLineArtModel {
    val spec = ModelSpecs.byId(prefs.getString("model_id", null) ?: "") ?: ModelSpecs.INFORMATIVE
    val id = if (models.isAvailable(spec.id)) spec else ModelSpecs.INFORMATIVE   // never use a missing model
    return OnnxLineArtModel(app, id, models.file(id.id), longSide = 768)          // accel: persisted, default XNNPACK
}
```
- Pick model: `fun selectModel(id)` -> if `models.isAvailable(id)`: save id, `lineArtModel?.close(); lineArtModel = null`, rerun generation. Otherwise show Download.
- Subject-cropped input: keep `longSide = 768`; 1024 is allowed via `model().longSide = 1024` (no rebuild needed).
- Accel setting (4 options CPU / XNNPACK / NNAPI GPU / NNAPI NPU): `model().selectAccel(a)` (persists to prefs "sketcher_ml"/"accel"). Show `model().activeAccel` and `model().lastFallbackReason` (non-null = requested accel was refused; show as a small warning). They are populated after the first infer or `warmUp()`.
- Benchmark button: on `Dispatchers.Default`, `val best = model().autoSelectAccel()` (runs ~4 providers x 2 inferences at 512, blocking, several seconds, sets and persists the fastest). For the table use `model().benchmark()` (Map<Accel, ms>; missing key = provider failed) or `OnnxLineArtModel.savedBenchmarkMs(ctx, accel)`. Show a progress spinner; no cancellation.
- Download: on `Dispatchers.IO`
  `models.download(id, onProgress = { done, total -> state.update { it.copy(dl = done to total) } })` (total = -1 if unknown). Catches `IOException` -> error text (network, HTTP code, sha256 mismatch); `InterruptedIOException` = cancelled via `shouldCancel = { !isActive }`. `models.delete(id)` frees space (bundled cannot be deleted). Use `models.list()` + `isAvailable(id)` to render rows (name, description, Download/Delete/Use).

## UI
Model picker rows from `models.list()`; selected radio only if available. Accel dropdown + "Auto (benchmark)" button + a status line "Running on X" / fallback reason. Download shows `LinearProgressIndicator(done/total)`.

## Notes
- NNAPI_GPU = FP16 + CPU_DISABLED; NNAPI_NPU = NCHW + CPU_DISABLED. ORT's Java API cannot choose the NNAPI device, so these may behave identically. NNAPI needs static shapes; with dynamic H/W it may silently run on ORT CPU, which the benchmark will reveal. Runtime failures auto-fall back (NNAPI -> XNNPACK -> CPU) and set `lastFallbackReason`.
- Anime model uses sizes that are multiples of 256 (rounded up, aspect slightly stretched like controlnet_aux); it is slower, so prefer `longSide = 768`.
- Model sha256/size are not set (files not fetched); fill `ModelSpec.sha256/sizeBytes` in `ModelSpecs` to enable verification and progress totals.
- Timing logs: `adb logcat -s SketcherML`.
