# F13 wiring: line model picker + Processing (ML) settings

## StylePickerSheet (new optional params, all defaulted)
`models: List<LineModelUi>`, `selectedModelId: String?`, `onSelectModel(id)`, `onDownloadModel(id)`, `onOpenMlSettings: (() -> Unit)?` (gear icon in header; hidden when null).
`LineModelUi(id, name, subtitle, sizeLabel, installed, downloading: Float?, recommended)` is declared in ui/generate/StylePickerSheet.kt.
Row shows only when `models` is non-empty and lineSource is AUTO or AI. Uninstalled cards are not selectable (download first).
Copy: Informative "Built-in, balanced"; Realistic "ControlNet lineart, detailed"; Coarse "Bold simple lines, great for poses"; Anime "Best for 3D/anime characters; large download".

## MlSettingsSheet (ui/settings/MlSettingsSheet.kt)
Params: accelOptions (id,label) = auto "Auto (fastest)", cpu "CPU", xnnpack "CPU + XNNPACK", nnapi_gpu "GPU (NNAPI)", nnapi_npu "NPU (NNAPI)"; selectedAccel; onSelectAccel; benchmarkResults Map<id, Long?> (null = unsupported, absent = not run); benchmarking; onRunBenchmark; lastInferenceMs; activeAccelLabel; fallbackReason; onDismiss.

## ViewModel needs
- `lineModels: StateFlow<List<LineModelUi>>` (map ModelManager state + download progress), `selectedLineModelId`, `selectLineModel(id)`, `downloadLineModel(id)`.
- `showMlSettings: Boolean` + `openMlSettings()/closeMlSettings()`.
- `selectedAccel: String` (persist in DataStore), `selectAccel(id)`, `benchmarkResults`, `benchmarking`, `runBenchmark()`, `lastInferenceMs`, `activeAccelLabel`, `fallbackReason` (from the Accel fallback in OnnxLineArtModel).
- Map Accel enum (CPU, XNNPACK, NNAPI_GPU, NNAPI_NPU) to ids above; "auto" = ViewModel logic (best benchmark result, else XNNPACK).

## Entry points
1. TopBar overflow item "Processing (GPU/CPU)" -> `openMlSettings()`.
2. Pass `onOpenMlSettings = vm::openMlSettings` to StylePickerSheet (gear icon). Render `MlSettingsSheet` in EditorScreen when `showMlSettings`.
