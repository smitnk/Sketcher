# F3 wiring: StylePickerSheet

New: `ui/generate/StylePickerSheet.kt`
`StylePickerSheet(settings: PipelineSettings, onSettingsChange: (PipelineSettings)->Unit, onGenerate: ()->Unit, onDismiss: ()->Unit, sourceThumbnail: ImageBitmap?)`
Also `StyleSettingsDialog(settings, onSettingsChange, onGenerate, onDismiss, sourceThumbnail = null)` overload (same thing). The old `StyleSettingsDialog(current: GeneratorSettings, onDismiss, onApply)` is untouched and still compiles.

## ViewModel
- `var pipelineSettings by mutableStateOf(PipelineSettings())` (com.smitnk.sketcher.image.pipeline).
- `generate()` must convert the source bitmap to ARGB IntArray (`getPixels`) and call
  `SketchPipeline.run(argb, w, h, pipelineSettings, model, progress)` in a coroutine (Dispatchers.Default),
  `model` = `OnnxLineArtModel` or null; map `progress(stage, fraction)` to the generating indicator.
  Result `GeneratedDrawing` replaces the old generator call.
- Keep `settings: GeneratorSettings` only if still used elsewhere.

## EditorScreen (replace the `if (showSettings)` block)
```kotlin
if (showSettings) {
    StylePickerSheet(
        settings = vm.pipelineSettings,
        onSettingsChange = { vm.pipelineSettings = it },
        onGenerate = { showSettings = false; vm.generate() },
        onDismiss = { showSettings = false },
        sourceThumbnail = vm.sourceThumbnail, // ImageBitmap? (e.g. downscaled source.asImageBitmap()), null is fine
    )
}
```
Style mapping: Outline only = shading NONE, colourFill false; Outline + Shading = shading MEDIUM (user may change level); Colour fill = colourFill true, shading NONE.
Ranges: lineWidth 1..5, fillColors 4..24, fillSpacing 3..12.
